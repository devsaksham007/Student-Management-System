# Student Management System Examples

## JSON File Reader

The JSON reader loads a JSON file and prints its contents with readable
indentation. Run it with:

```text
python json_reader.py
```

Enter the path to a JSON file when prompted.

## Contact Book Using a Dictionary

This program stores contacts in a Python dictionary. It can add, search, update,
delete, and display contacts.

Run it with:

```text
python contact_book.py
```

Choose an option from the menu when prompted. Tests can be run with:

```text
python -m unittest
```
